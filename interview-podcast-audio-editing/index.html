Interview audio editing / Practical guide

How a two-person interview becomes a publish-ready podcast

An interview is often compelling before it is technically comfortable to hear. The editing job is to protect the conversation while removing distractions and making both voices sit together.

Interview audio editingAUDIO ONLY

Start from separately recorded speakers

When possible, keep the host and guest on separate tracks. Listen to each before processing and note clipping, room noise, inconsistent mic distance and accidental overlap. A mixed single file limits how independently each voice can be treated.

  • Preserve original files and the source duration.
  • Record which person is on which track.
  • Check timing drift before detailed editing.

Confirm what content should stay

Technical finishing is different from deciding the narrative. If the host already has a cut, use that approved version and make only the marked minor trims. Extensive story restructuring, filler-word deletion or rewriting transitions should be separately scoped.

Clean without making voices unnatural

Use modest EQ to improve intelligibility, reduce constant background noise where safe, and control sudden level jumps. Aggressive denoising can create metallic artifacts, while over-compression makes speech tiring.

Listen to the transitions, not only peaks

Compare speaker switches, opening music, silence and closing sections at realistic listening volume. Integrated loudness statistics help but cannot replace listening, particularly where one voice is much quieter.
